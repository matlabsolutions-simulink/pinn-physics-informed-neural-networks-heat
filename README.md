## 🎯 Overview & Problem Statement
Physics-Informed Deep Neural Network solving 1D transient heat equation without grid discretization, enforcing thermal diffusion PDE physics directly in the loss function.

This repository provides verified, modular MATLAB source code and analytical formulas designed for university research, ABET/CEAB engineering labs, capstone design, and industrial modeling.

---

## 📐 Mathematical Formulation & Governing Equations

- **Governing 1D Heat Diffusion PDE:**
  $$\frac{\partial u}{\partial t} - \alpha \frac{\partial^2 u}{\partial x^2} = 0, \quad x \in [0, L], \; t > 0$$
- **Composite Physics Loss Function:**
  $$\mathcal{L} = \mathcal{L}_{residual} + \lambda_{bc} \mathcal{L}_{boundary} + \lambda_{ic} \mathcal{L}_{initial}$$

## 🚀 Quickstart & Execution

### Prerequisites
- MATLAB R2022b, R2023b, R2024a, or R2024b
- Base MATLAB (Zero paid proprietary third-party toolboxes required for this starter script)

### Running the Benchmark Simulation
1. Clone this repository:
   ```bash
   git clone https://github.com/matlabsolutions-simulink/pinn-physics-informed-neural-networks-heat.git
   cd pinn-physics-informed-neural-networks-heat
   ```
2. Open MATLAB and navigate to the project directory.
3. Run the primary entry script in the MATLAB Command Window:
   ```matlab
   run_pinn_heat_conduction
   ```
